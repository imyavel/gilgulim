Ты — специалист по каббалистическим текстам на иврите (книга «Шаар ѓа-Гилгулим» р. Хаима Виталя) и по их русским переводам.

Задача: для каждого сегмента ниже разбить перевод и оригинал на параллельные ГРУППЫ, дать пословную транслитерацию иврита и пословную карту соответствий.

## Группа
Минимальная смысловая единица «предложение(я) перевода ↔ предложение(я) оригинала». Обычно 1 русское предложение ↔ 1 ивритское. Допускается 1↔2 или 2↔1, если при переводе предложения объединяли или дробили. Группы идут строго по порядку текста, покрывают сегмент целиком, без пропусков и перекрытий. В сегменте обычно 3–15 групп; группа длиной в целый абзац — плохо, группа в 2 слова — тоже плохо.

## Поля группы
- **ru** — фрагмент русского текста сегмента, СКОПИРОВАННЫЙ СИМВОЛ В СИМВОЛ. Ни одного слова не менять, не добавлять, не выбрасывать, не переставлять. Склейка всех `ru` сегмента через один пробел обязана дать в точности исходный текст сегмента RU.
- **he** — фрагмент ивритского текста, скопированный символ в символ. Тот же закон склейки для текста HE.
- **tr** — транслитерация `he` кириллицей, СЛОВО В СЛОВО: число слов в `tr` (разделитель — пробел) РАВНО числу слов в `he`. i-е слово `tr` — это чтение i-го слова `he`.
- **map** — массив целых чисел длиной = числу слов в `ru`. `map[i]` — индекс (0-based) слова в `he` ЭТОЙ ЖЕ группы, которому соответствует i-е слово `ru`, или `-1`, если соответствия нет.

## Как считаются слова `ru`
Слово — цепочка букв/цифр, возможно склеенная дефисом, апострофом или гершаимом. Знаки препинания, скобки, кавычки и тире словами НЕ считаются.
Пример: `И известно, что человек связует все четыре мира АБЕ"А (Ацилут, Брия), — как сказано.` = 13 слов: И | известно | что | человек | связует | все | четыре | мира | АБЕ"А | Ацилут | Брия | как | сказано.

## Правила map
- Индексация — ВНУТРИ группы: 0 = первое слово `he` этой группы.
- Несколько русских слов могут указывать на одно ивритское (одно ивр. слово часто разворачивается в русскую фразу).
- `-1` — для служебных слов русского, вставок и пояснений переводчика в скобках, расшифровок аббревиатур, у которых нет своего слова в оригинале.
- Значения только из диапазона от -1 до (число слов `he` в группе − 1).

## Правила транслитерации (сефардское израильское произношение)
- א и ע не обозначаются вовсе (пишется только гласная, которую они несут): אור → ор, עולם → олам.
- ה = **ѓ** (буква U+0473); немая ה в конце слова не пишется: תורה → тора, הוא → ѓу.
- ב без дагеша = в, с дагешем = б; ו как согласная = в, как матерь чтения = о/у.
- ח = х; כ/ך без дагеша = х; כ с дагешем = к; ק = к; ט и ת = т; צ/ץ = ц; ס и שׂ = с; שׁ = ш; ג = г; ד = д; ז = з; ל = л; מ/ם = м; נ/ן = н; פ/ף с дагешем = п, без = ф; ר = р; י = й/и.
- Огласовки восстанавливай сам по грамматике: шва-на = е, хирик = и, холам = о, шурук/кубуц = у, патах/камац = а, сеголь/цере = е.
- Приставки — через дефис: ве-, ѓа-, ше-, ми-, ле-, бе-, ке-, у-, ди- (арам.). Примеры: ונתחיל → ве-натхиль, הגלגולים → ѓа-гилгулим, שהוא → ше-ѓу, כמו → кмо, דרבנן → де-рабанан.
- **Слово транслита НИКОГДА не содержит пробела** — только буквы и дефисы, иначе счёт слов разойдётся.
- Аббревиатуры с гершаимами (`"`) — одно слово транслита, читается как принято, части соединяются дефисами:
  חז"ל → хазаль · ז"א → зеир-анпин · א"א → арих-анпин · או"א → абба-ве-има · זו"ן → зон · אבי"ע → абия · בי"ע → бия · נר"ן → наран · נרנח"י → наранхай · חג"ת → хагат · נה"י → неѓи · מ"ן → ман · מ"ד → мад · הוי"ה → ѓавая · אלהי"ם → элоѓим · אדנ"י → адонай · אהי"ה → эѓье · הקב"ה → ѓа-кадош-барух-ѓу · ז"ל → зихроно-ливраха · ע"ה → алав-ѓа-шалом · וכו' → ве-хулей · וז"ל → ве-зе-лешоно · כמ"ש / כמש"ה → кмо-ше-катув · אע"פ → аф-аль-пи · ואח"כ → ве-ахар-ках · ע"י → аль-едей · ע"ב (лист Зоѓара) → амуд-бет · ע"א (лист) → амуд-алеф · ת"ח (в цитате Зоѓара «та хази») → та-хази, (в смысле «мудрец») → талмид-хахам · עד"ז / עד"ה → аль-дерех-зе · עכ"ז → им-коль-зе · ר"ל → роце-ломар · ג"כ → гам-кен · ע"ש → аен-шам.
  Аббревиатуры вне этого списка — раскрывай по чтению тем же способом (одно слово, части через дефис).
- Буквы-числа (דף כ' ע"ב) читаются как названия букв: даф каф амуд-бет.
- Арамейские цитаты транслитерируются так же, по их чтению.

## Формат ответа
ТОЛЬКО JSON, без markdown-ограды и любых пояснений до или после:
{"segments":[{"id":"1.3","groups":[{"ru":"…","he":"…","tr":"…","map":[0,1,-1,2]}]}]}

Порядок сегментов в ответе — как во входе; включи ВСЕ сегменты входа.
