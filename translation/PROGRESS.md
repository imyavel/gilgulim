**ТОЧКА ВХОДА ПРОЕКТА. Самодостаточна для продолжения с чистого контекста.**

## Что это

Полный перевод на русский язык книги «Врата кругооборотов» (שער הגלגולים) рабби Хаима Виталя (учение АРИ). Работа идёт этапами, **каждый этап запускается только по команде оператора** («делай этап N» или «следующий этап»). Без команды ничего не переводить.

## Файлы проекта (все в `translation/` репо сайта `C:\Users\admin\imyavel\gilgulim\`)

С 2026-09-19 перевод и сайт-читалка — в одном репо imyavel/gilgulim (публичное, GitHub Pages); сборка сайта читает перевод и оригинал отсюда. Пути ниже — относительно `translation/`.

- `PROGRESS.md` — этот файл: план, статусы. Обновлять после каждого этапа.
- `source\gilgulim_he.md` — полный ивритский исходник, 41 хакдама, сегменты помечены `[N.s]`. Скачан с Sefaria (api/texts/Sha'ar_HaGilgulim), 91 363 слова. НЕ редактировать.
- `glossary.md` — согласованный канон передачи аббревиатур и терминов. ОБЯЗАТЕЛЕН: читать перед каждым этапом, следовать строго.
- `translation.md` — общий файл перевода. Каждый этап ДОПИСЫВАЕТ свои главы в конец. Уже переведённое не трогать (кроме прямой команды оператора).

## Процедура этапа

1. Прочитать `glossary.md` целиком и раздел «Правила перевода» ниже.
2. Взять из `source\gilgulim_he.md` диапазон этапа (по меткам `[N.s]`).
3. Переводить последовательно, сегмент за сегментом. Каждый сегмент перевода начинать меткой `**[N.s]**`. Главу начинать заголовком `## Хакдама N`. Если этап начинается с середины главы (этапы 8, 9) — заголовок не повторять, продолжать сегменты той же главы.
4. Дописывать готовый перевод в конец `translation.md` порциями (по ~10–20 сегментов), НЕ копить всё в контексте — чтобы обрыв сессии не терял работу. При возобновлении после обрыва: посмотреть последнюю метку `[N.s]` в `translation.md` и продолжить со следующего сегмента.
5. По завершении этапа: перегенерировать RTF-выдачу командой `python md2rtf.py` (из `translation/`; переводит весь `translation.md` в `translation.rtf` — итоговый файл для оператора; генерируется локально, в git не хранится — `.gitignore`). Затем обновить таблицу статусов ниже (статус, дата), сообщить оператору и ОСТАНОВИТЬСЯ. Следующий этап — только по новой команде.
6. Черновики порций складывать в `parts\pNN.md` (Write → `cat >> translation.md`) — так обрыв сессии не теряет работу. Порции этапов 1–10 в репо не переносились — архив: `C:\Users\admin\_archive_pipelines\gilgulim_translation_2026-09-19\parts\`.
7. После этапа пересобрать сайт-читалку (тот же репо, https://imyavel.github.io/gilgulim/): `python tools/align.py && python tools/build.py` из корня репо (уровнем выше `translation/`), проверить, закоммитить правку перевода вместе с пересборкой и push под imyavel (см. `README.md` и `PROJECT.md` в корне репо). Обновить в ТЗ/README «переведено до хакдамы N».

## Правила перевода

- Аббревиатуры — строго по `glossary.md`: смысловые переводить, термины раздела 2 раскрывать (Адам Ришон), термины раздела 3 оставлять свёрнутыми (З"А, АВ"И, АВА"Я, МА"Н…) с полной формой в скобках при первом появлении В ПЕРЕВОДЕ ВООБЩЕ (проверять по translation.md, не по этапу).
- Формулы-маркеры (ונלע"ד, וז"ס, וצ"ע) — фиксированными оборотами из глоссария, без вариаций.
- הקב"ה во всех формах — «Творец, Свят Благословен Он» («Творец» склоняется, апозиция неизменна, запятая обязательна): правило T001 словаря перевода Зоѓара, решение оператора 2026-09-19; применено ко всем 35 местам книги.
- Стиль: точный, без пересказа и упрощения; русский синтаксис живой, не калька. Стихи Писания цитировать по смыслу с ивритского оригинала, в кавычках, с указанием источника в скобках, если он назван в тексте.
- Ничего не пропускать и не добавлять. Сомнительное место — переводить буквально и ставить пометку `<!-- TODO: уточнить -->`.
