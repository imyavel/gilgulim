# Врата кругооборотов — Шаар ѓа-Гилгулим

Сайт-читалка русского перевода книги «Шаар ѓа-Гилгулим» р. Хаима Виталя (по учению АРИ):
перевод, ивритский оригинал и пословная транслитерация.

Живая версия: <https://imyavel.github.io/gilgulim/>

## Что внутри

- `index.html` — весь сайт: вёрстка, стили и логика (ванильный JS, без фреймворков).
- `data.json` — данные книги: главы → сегменты → группы. Группа — параллельная пара
  «предложение(я) перевода ↔ предложение(я) оригинала» с полями:
  - `ru` — фрагмент перевода, `he` — фрагмент оригинала (дословно, как в источниках);
  - `tr` — транслитерация `he` кириллицей, слово в слово (число слов совпадает с `he`);
  - `map` — для каждого слова `ru` индекс соответствующего слова `he` (или `-1`).
- `data/align/<N.s>.json` — кэш выравнивания по сегментам (дорого получен через LLM,
  поэтому лежит в репозитории и не пересчитывается).
- `tools/` — сборка.

## Как пользоваться

- Слева — оглавление: хакдамот и параграфы; раскрыта текущая глава, активный параграф
  подсвечен. Адрес вида `…/gilgulim/#3.5` открывает конкретный параграф.
- Кнопки `RU | HE` переключают перевод и оригинал (выбор запоминается).
- **Shift + наведение мышью** на предложение в русском режиме показывает всплывающее окно
  с ивритским оригиналом и транслитерацией; слово под курсором подсвечивается в оригинале
  и транслитерации.

## Сборка

Источники лежат вне репозитория (только для чтения):
`C:\Users\admin\gilgulim\translation.md` и `C:\Users\admin\gilgulim\source\gilgulim_he.md`.

```sh
python tools/align.py     # выравнивание новых сегментов через headless Claude (кэш)
python tools/build.py     # сборка data.json из источников и кэша
```

`align.py` обрабатывает только сегменты, которых нет в кэше, батчами, проверяет
целостность (тексты групп режутся из источника — ни одно слово не может измениться)
и счётчики слов; несошедшиеся сегменты после трёх попыток попадают в
`data/align_errors.md`. `build.py` печатает статистику и повторно проверяет целостность.

Полезные ключи: `--only 3.5,3.6` (конкретные сегменты), `--limit N`, `--jobs N`, `--force`.
