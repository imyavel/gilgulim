# Врата кругооборотов — Шаар ѓа-Гилгулим

Сайт-читалка русского перевода книги «Шаар ѓа-Гилгулим» р. Хаима Виталя (по учению АРИ):
перевод, ивритский оригинал и пословная транслитерация.

Живая версия: <https://imyavel.github.io/gilgulim/>

## Что внутри

- `1.html` … `40.html` — по странице на главу (генерирует `tools/build.py`). Русский текст главы
  лежит прямо в разметке (читается без JS); иврит, транслитерация и пословные соответствия
  этой главы встроены в страницу JSON-блоком. Общий `data.json` страницы не загружают.
- `app.css`, `app.js` — общие стили и логика страниц (ванильный JS, без фреймворков).
- `index.html` — вход: переадресация на главу 1, а старых адресов `#N.s` — на `N.html#N.s`.
- `data.json` — полный артефакт сборки: главы → сегменты → группы. Группа — параллельная пара
  «предложение(я) перевода ↔ предложение(я) оригинала» с полями:
  - `ru` — фрагмент перевода, `he` — фрагмент оригинала (дословно, как в источниках);
  - `tr` — транслитерация `he` кириллицей, слово в слово (число слов совпадает с `he`);
  - `map` — для каждого слова `ru` индекс соответствующего слова `he` (или `-1`).
- `data/align/<N.s>.json` — кэш выравнивания по сегментам (дорого получен через LLM,
  поэтому лежит в репозитории и не пересчитывается).
- `tools/` — сборка: `page.html` — шаблон страницы главы, `build.py`, `align.py`, `prodcheck.py`.
- `translation/` — исходники перевода: `translation.md` — первоисточник русского текста,
  `source/gilgulim_he.md` — ивритский оригинал (Sefaria), `glossary.md` — глоссарий терминов,
  `PROGRESS.md` — ход и правила перевода, `md2rtf.py` — выгрузка в RTF.

## Как пользоваться

- Каждая глава — отдельная страница: `…/gilgulim/3.html`; адрес `…/gilgulim/3.html#3.5` открывает
  параграф. Старые ссылки вида `…/gilgulim/#3.5` продолжают работать.
- Слева — оглавление: все главы («Глава 1» … «Глава 40»), у текущей раскрыт список параграфов,
  активный параграф подсвечен. Внизу главы — ссылки на предыдущую и следующую.
- Кнопки `RU | HE` переключают перевод и оригинал (выбор запоминается для всех страниц).
  В режиме HE оглавление, заголовки и номера параграфов — на иврите (הקדמה א׳, [ב׳]).
- **Shift + наведение мышью** на предложение или на заголовок главы в русском режиме
  показывает всплывающее окно с ивритским оригиналом и транслитерацией; слово под курсором
  подсвечивается в оригинале и транслитерации.
- Второй клик по активному параграфу в оглавлении ставит отметку «здесь остановился»
  (одна на книгу; на других страницах видна на строке своей главы).

## Сборка

Сборка читает перевод и оригинал из `translation/`: `translation/translation.md` и
`translation/source/gilgulim_he.md`.

```sh
python tools/align.py     # выравнивание новых сегментов через headless Claude (кэш)
python tools/build.py     # сборка data.json, страниц глав и index.html из источников и кэша
```

`align.py` обрабатывает только сегменты, которых нет в кэше, батчами, проверяет
целостность (тексты групп режутся из источника — ни одно слово не может измениться)
и счётчики слов; несошедшиеся сегменты после трёх попыток попадают в
`data/align_errors.md`. `build.py` печатает статистику, повторно проверяет целостность
и сверяет текст в разметке каждой страницы с проверенными группами.

Полезные ключи: `--only 3.5,3.6` (конкретные сегменты), `--limit N`, `--jobs N`, `--force`.

Проверка сайта (локально — сервер, отдающий репозиторий под путём `/gilgulim/`):

```sh
python tools/prodcheck.py [URL] [--shots DIR]
```
